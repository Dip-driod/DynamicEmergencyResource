# Dynamic Emergency Resource Coordination

A simulation-based emergency resource coordination system
designed to study the allocation and dynamic reallocation
of limited emergency resources under changing conditions.

## 📌 Project Overview

Emergency response systems operate in environments where
incident demand, resource availability, and operational
conditions can change over time.

This project explores how emergency resources, such as
ambulances, can be allocated and reassigned when new
incidents occur or existing conditions change.

The system uses simulated emergency incidents and
resources to evaluate coordination strategies through
performance metrics.

## 🎯 Research Objective

To evaluate the effectiveness and trade-offs of dynamic
emergency resource reallocation under changing conditions
through simulation-based experiments.

## 🔬 Research Focus

- Emergency incident generation
- Resource allocation
- Dynamic resource reallocation
- Changing emergency conditions
- Simulation-based experimentation
- Performance evaluation

## 🚀 Current Features

- Simulated emergency incidents
- Simulated ambulance resources
- Incident priority levels
- Initial ambulance assignment
- Assigned and unassigned incident tracking
- Browser-based dashboard
- Simulation performance metrics

## 🛠️ Technology Stack

- JavaScript
- Node.js
- HTML5
- CSS3
- Python (simulation support and experiments)
- Git and GitHub

## 🧪 Planned Research Experiments

The project will evaluate allocation strategies under
different simulated conditions, including:

- Low incident demand
- High incident demand
- Limited resource availability
- Critical incident arrivals
- Resource failures
- Changing operational conditions

Performance will be evaluated using metrics such as:

- Average response time
- Unassigned incidents
- Resource utilization
- Reallocation frequency
- Computational time

## 🗺️ Project Scope

This is a simulation-based research prototype.
It does not currently integrate with real emergency
dispatch systems, live GPS hardware, or operational
emergency services.

## 📚 Research Reference

The project is inspired by research in dynamic emergency
resource coordination and allocation.

The implementation is developed as a simplified prototype
for academic research and experimentation.
